# Charcut'SN Backend

Backend NestJS modulaire pour la marketplace Charcut'SN.

## Demarrage

```bash
npm install
cp .env.example .env
npm run prisma:generate
npm run build
npm run start:dev
```

API par defaut : `http://localhost:4000/api/v1`.

Documentation OpenAPI : `http://localhost:4000/docs`.
